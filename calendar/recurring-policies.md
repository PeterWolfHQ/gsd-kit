# Recurring Event Policies

How `/calsweep`, `/next` and `/review` treat recurring calendar events, by title match.

Policies: **ignore** (invisible) · **night-before** (warn the evening prior) · **action-item** (each occurrence becomes an inbox capture, once) · **free-window** (bonus focus time; `/next` leans toward bigger items)

Unknown recurring events: `/calsweep` asks the user to classify them, then appends a row here.
